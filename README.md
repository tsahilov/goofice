# gooffice

Одна карточка — одна отметка о походе в офис. HTML, CSS и JavaScript, без сборки, установки пакетов и серверной части приложения.

## Просмотр

Откройте `index.html` в браузере. Для проверки обмена отметками между вкладками используйте один локальный адрес:

```powershell
node tools/preview.cjs
```

Затем откройте http://127.0.0.1:4173 в двух вкладках одного браузера. Остановить предпросмотр — `Ctrl+C`.

## Использование

Выберите имя в шапке. Нажмите на день, чтобы добавиться, повторите для снятия отметки. При первом нажатии без имени выберите его в шапке — исходное действие применится автоматически. Escape отменяет ожидающий выбор. Для просмотра календаря выбирать имя не нужно.

Имена внутри карточки идут по времени добавления. После снятия и повторного добавления имя становится последним. Смена пользователя меняет только персональные акценты. Enter и пробел работают на кнопках; фокус отмечен чёрным пунктиром.

Десктоп показывает 14 дней в семь колонок. На экранах шириной менее 768 px показывается вертикальный список от сегодняшнего дня и закреплённая шапка. Прошедшие даты недоступны для редактирования. День определяется в часовом поясе офиса Europe/Moscow, даже если у браузера другой часовой пояс. Открытый календарь обновляется в офисную полночь.

## Файлы и проверка

- `index.html`, `styles.css` — оформление по макетам, локальный шрифт из `assets/fonts/`.
- `data.js` — участники и цвета, часовой пояс, календарь, модель и localStorage.
- `app.js` — отображение, выбор участника и нажатия на карточки.
- `tests/project.test.cjs` — тесты стандартными средствами Node.js.
- `tools/preview.cjs` — необязательный статический предпросмотр, включая локальные шрифты.
- `references/desktop.png`, `mobile.png`, `states.png` — актуальные пользовательские референсы. `design.png` — предыдущий макет.
- `preview/desktop.jpg`, `mobile.jpg` — снимки результата.
- `SPEC.md` — действующие правила.

```powershell
node --check data.js
node --check app.js
node --test tests/project.test.cjs
```

Проверка новой концепции: 15 тестов пройдены. В браузере проверены просмотр без имени и первое нажатие, добавление и снятие отметки, персональные акценты, порядок и повторное добавление, сохранение после перезагрузки, обмен между вкладками, недоступность прошлых дат, мобильное скрытие, закреплённая шапка при прокрутке, клавиатурный фокус и hover. На ширинах 320–1440 px горизонтального переполнения нет. Оба локальных начертания загружаются; ошибок в консоли нет. Снимки сохранены в `preview/`.

Имена, ID и персональные цвета находятся только в `MEMBERS` в `data.js`. Часовой пояс — в `OFFICE_TIME_ZONE`. Сохраняйте ID при переименовании, чтобы сохранить связанные отметки.

## Данные и ограничения

Запись хранится отдельно для каждой пары «дата + участник»: `{id, date, memberId, createdAt}`. Это позволяет менять отметку без перезаписи чужих записей и позже заменить хранилище на документы Firestore. При совпадении времени новых отметок используется стабильный ID. Изменения одного человека в одном дне подчиняются последней записи; отдельного разрешения конфликтов пока нет.

Обмен идёт только между вкладками одного браузера на одном адресе. Между браузерами и устройствами данных пока нет. Если localStorage недоступен, работает память вкладки до перезагрузки; через `file://` сохранение зависит от браузера.

Схема обновлена с v1 на v2. Старые записи не удаляются и не переименовываются. Положительные отметки `yes`/`maybe` совпадающих участников переносятся один раз; `no` не переносится. Из прежнего тестового списка в новом осталась Аня. Остальным прежним ID не назначаются новые имена: исходные записи остаются в старом пространстве данных. Восстановить время старых отметок нельзя, поскольку v1 его не сохраняла. Уже открытые старые страницы нужно обновить, чтобы они перешли на v2.

На чистом хранилище создаются небольшие тестовые данные. При миграции прежних записей образцы не добавляются поверх пользовательских данных. Новые недели не заполняются автоматически, прошлая неделя v2 удаляется без архива.

Firebase и публикация не подключены.
