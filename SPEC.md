# gooffice — спецификация

Минимальный календарь команды без регистрации. HTML, CSS и JavaScript, без сборки и внешних зависимостей. До отдельного этапа Firebase используется localStorage.

## Участники и отметки
- Список, постоянные ID и персональные цвета централизованы в `data.js`: Алан, Денис, Аня, Даша.
- Смотреть календарь можно без выбора имени. Имена выбираются прямо в шапке; выбор запоминается. Любой может править отметки любого участника.
- Вся карточка — одна кнопка. Нажатие добавляет отметку текущего участника, повторное снимает. Других статусов и вложенных кнопок нет.
- Первое нажатие без выбранного имени переводит фокус к именам. Выбор имени сразу применяет исходное нажатие. Escape отменяет ожидающее действие.
- В карточке перечислены только отметившиеся, строго в порядке добавления. Повторное добавление после удаления помещает участника в конец. Смена пользователя порядок не меняет.
- Акцент выбранного участника одновременно используется в его имени в шапке, его имени в карточке и тонкой обводке выбранной карточки. Все остальные имена чёрные. Цвет задан одной CSS-переменной `--accent-color`.

## Даты
- Часовой пояс офиса — `Europe/Moscow` (константа `OFFICE_TIME_ZONE` в `data.js`). Он одинаков для всех браузеров.
- Две полные недели, понедельник–воскресенье, включая выходные. При наступлении понедельника прошлая неделя удаляется, новая добавляется.
- Прошедший день определяется по календарному дню офиса; сравнения текущих дат как строк UTC нет.
- Прошедшие дни не редактируются. На десктопе они остаются в сетке с opacity 0.1; на мобильном исключаются из раскладки (`display: none`), список начинается с сегодняшнего дня.
- Обновление при офисной полуночи, возврате на вкладку и восстановлении фокуса. Новые даты пустые; отметки общей недели сохраняются.

## Отображение
- Десктоп от 768 px: семь колонок, дни недели только над первой строкой; перед второй — разделитель «Следующая неделя».
- Мобильный: один столбец, день недели над каждой карточкой, непрозрачная шапка закреплена сверху; контент прокручивается под ней.
- Локальный вариативный Medeo Sans, обычное и курсивное начертания, веса 100–900. Вступительный текст и курсив — по макетам в `references/`.
- Карточки белые, скруглённые, с деликатной тенью. Hover серый только для доступных дней на устройствах с hover. Пунктирный focus-visible отличается от персональной обводки и не меняет размеры карточки.

## Хранение первого этапа
- Одна независимая JSON-запись на дату и участника: `{id, date, memberId, createdAt}`. Ключ: `gooffice.demo.v2.attendance.<дата>.<участник>`.
- При добавлении `createdAt` монотонно возрастает относительно уже видимых отметок; при совпадении времени одновременных добавлений используется стабильный порядок по `id`.
- Изменение одной отметки не перезаписывает общий список: разные вкладки не теряют записи других участников. События `storage` обновляют отображение.
- При изменении одного и того же участника в нескольких вкладках действует последняя запись localStorage. Между устройствами обмена пока нет.
- Выбор имени в уже открытых вкладках независим. При перезагрузке используется последнее сохранённое имя.
- Недоступное хранилище заменяется памятью вкладки с пояснением на странице.
- Старые v1-данные остаются нетронутыми. Положительные статусы `yes`/`maybe` для совпадающих ID переносятся один раз, отрицательные не переносятся. В новом списке из старого сохранилась Аня; участникам не назначаются чужие имена. Старый порядок восстановить нельзя: v1 не хранила время.

## Проверка
Автоматические тесты: календарь, офисная полночь, разные часовые пояса браузера, месяц/год/високосный февраль, порядок и повторное добавление, сохранение, миграция, независимые записи и одинаковое время, недоступное хранилище.
В браузере: реальные нажатия и клавиатура, синхронные акценты, порядок, две недели, запрет прошлых дней, мобильное скрытие и закрепление шапки, переполнение, шрифт, снимки экрана.

## Вне объёма
Firebase, публикация, авторизация, уведомления, админка, архив, подтверждения, дополнительные продуктовые функции.
