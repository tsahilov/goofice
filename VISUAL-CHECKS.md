# Проверка типографики и анимаций

Изменены только оформление и визуальные реакции подтверждённых состояний. Firebase-конфигурация, cloud-store.mjs, firestore.rules, данные, порядок участников, календарные правила и тексты не менялись. Совпадение SHA-256 cloud-store.mjs и firestore.rules с предыдущим протоколом проверки подтверждено.

## Реализация

- Root: 16px; единая переменная --font-size: 1.3rem. Весь видимый текст — 20.8px, включая вложенный курсив, даты и имена.
- Hover: прежний цвет #f3f3f3. Вход — 0ms, выход — 300ms с мягким easing. У выбранного имени сохраняется персональный цвет. Только hover: hover / pointer: fine; недоступные карточки исключены.
- Подчёркивание: ::after, scaleX(0→1), origin left, 210ms. Начальная восстановленная отметка показывается сразу. Абсолютное позиционирование не меняет ширины имён.
- Контур: настоящий SVG rect, pathLength=1000, stroke-dashoffset 1000→0 за 380ms. Прозрачность линии не анимируется. ResizeObserver обновляет геометрию при переносе имён и смене ширины; vector-effect сохраняет одинаковую толщину. Скругление совпадает с радиусом карточки с поправкой на половину толщины линии.
- Прорисовка запускается только после успешного ответа существующего store.toggle. Если подтверждённый снимок приходит позже ответа, визуальный слой дожидается выбранного состояния карточки. При загрузке, удалённом обновлении и смене участника готовые обводки статичны.
- Снятие отметки, смена участника и пересоздание календаря отменяют старые анимации и ожидающие визуальные запросы.
- prefers-reduced-motion отключает CSS-переходы и подчёркивание; JavaScript не запускает SVG-анимации и немедленно отменяет текущие при смене настройки.
- Сохранены focus-visible и прозрачность/недоступность прошлых дней. На планшете subgrid выравнивает карточки по общей высоте подписей. На телефоне шапка переносит текст без уменьшения размера; её фактическая высота учитывается при прокрутке к фокусу.

## Выполненные проверки

- npm test: 27/27 (21 прежняя проверка + 6 проверок визуального слоя).
- npm run test:rules: 12/12 в официальном Firestore Emulator, без публикации правил и запросов в рабочую базу.
- node --check для app.js и visual-effects.mjs, git diff --check.
- Браузер: 320, 390, 640, 768, 900, 1024, 1280, 1440 px. Единственный вычисленный размер видимого текста — 20.8px. Горизонтального переполнения нет; на десктопе семь колонок. На планшете проверено совпадение верхних координат всех карточек первой строки.
- Браузер: hover-фон rgb(243,243,243), transition-duration при наведении 0s, после ухода 0.3s. Такие же длительности проверены у имён; активное имя сохраняет цвет.
- Браузер: во время добавления stroke-dashoffset находился между 1000 и 0 (наблюдалось 51.4112px), opacity линии оставалась 1. После быстрого добавления/снятия aria-pressed=false, SVG visibility=hidden.
- Браузер: при смене имени у всех выбранных контуров stroke-dashoffset=0, цвет меняется сразу. Восстановленное подчёркивание имеет animation-name:none и scaleX(1).
- Браузер: высота rect после изменения карточки равна её высоте минус толщина линии. Ошибок консоли нет.
- Ограничение движения проверено отдельными тестами: отсутствие нового запуска, отмена текущей анимации и CSS-правило отключения переходов. Системная настройка Windows при проверке не менялась.

Визуальная проверка проводилась в изолированной локальной странице с тестовыми данными, которая загружает настоящие app.js/styles.css/visual-effects.mjs. Общие отметки команды не изменялись. Снимки — preview/desktop.jpg и preview/mobile.jpg. Локальный тестовый сервер после проверки остановлен. Публикация не выполнялась.
