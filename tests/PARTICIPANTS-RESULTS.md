# Проверка реестра на 20 участников

- `npm test`: **27/27**.
- Официальный Firestore Emulator 1.22.0, SDK 12.4.0, Java 25: **26/26**. Тесты запускались командой `node --test --test-concurrency=1 tests/firestore.emulator.test.mjs` с `FIRESTORE_EMULATOR_HOST=127.0.0.1:18086` в проекте `demo-gooffice-rules`. Порты из конфигурации CLI были недоступны; эмулятор запущен напрямую с `-Duser.language=en -Duser.country=US`, чтобы обойти ошибку локализации при проверке неверной даты. Отказы permission-denied в журнале относятся к отрицательным сценариям.
- Проверены 5-й, 12-й, 13-й, 19-й и 20-й профили, конкуренция двух клиентов за последнее место, запрет 21-го на клиенте и в правилах, дубликаты с разным регистром и пробелами, неизменность старых профилей, уникальные цвета, повторная загрузка и синхронизация.
- Проверены сохранение старых отметок при инициализации, отметки исходных и новых участников, чтение всех 20 действующих отметок при наличии 21 старой отметки удалённых ID, доступ прежнего клиента с limit(4), запрет записи за прошедшие даты и изменение отметки через create/delete.
- Браузер на отдельном демопроекте: 1280 px и мобильные области 320/390 px. Проверены автовыбор нового профиля, блокировка ввода при 20 профилях, выбор последнего имени, перенос списка без горизонтального скролла, закреплённая шапка, создание и снятие отметки с обновлением во второй вкладке. На десктопе ошибок в консоли не было. В мобильной оболочке iframe зафиксировано исключение MutationObserver без URL источника; сценарии внутри приложения прошли. Физические устройства и рабочая база не проверялись.

Тесты и браузерный предпросмотр обращались только к localhost; правила в рабочем проекте не публиковались.
